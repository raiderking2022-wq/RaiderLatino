# Raider-Latino

Plugin para **CloudStream 3**.

## Compilar

```sh
cd RaiderLatino
./gradlew RaiderLatinoPlugin:assembleRelease
```

El APK resultante estará en
`RaiderLatinoPlugin/build/outputs/apk/release/RaiderLatinoPlugin-release.apk`.

## Instalar en CloudStream

1. Abre CloudStream 3 en tu dispositivo Android.
2. Ajustes → Extensiones → "Instalar desde archivo" (o escanea el repositorio).
3. Selecciona el APK generado.
4. Aparecerá como proveedor **Raider-Latino**.
